**Desktop apps. AI tools. A Linux workspace in your pocket.**

## A workspace that fits your phone

| Feature | What you get |
| --- | --- |
| **Optimized for phone touchscreens** | Extensively optimized for touch, so the Linux desktop feels natural to use on your phone. |
| **Your choice: terminal or desktop mode** | If you prefer a terminal-only workspace, open the terminal directly without starting the graphical desktop. Both modes share your files and software. |
| **Development and AI tools** | Git and Python are included. Add Codex for help with development, documentation and task automation. |
| **Simple visual installation** | Choose your tools or open a compatible `.deb` package. Follow the prompts to install, with no commands to type. |
| **Easy sharing with Android** | Copy text and transfer files between Android and Linux as you work. |
| **Device hardware support** | Bring your phone's hardware into Linux. Speakers and the microphone are supported today, with room to extend support to more hardware. |

## Quick start

> **Download:** Get LinDesk on [Google Play](https://play.google.com/store/apps/details?id=linux.on.android.lindesk).

> [!IMPORTANT]
> **Android 12+: complete the child-process setup for your Android version.** Where the system provides **Disable child process restrictions**, turn it **ON** and keep Developer options enabled. **Android 11 needs no such setting.**
>
> Follow the [Android setup guide](docs/SETUP.md) for the appropriate method.

1. **Install LinDesk** from [Google Play](https://play.google.com/store/apps/details?id=linux.on.android.lindesk).
2. **Complete the preparation** under **Settings → Before you start**, then choose **Start desktop** or **Start terminal**. Allow the first initialization to finish.
3. **Make it yours.** Open an app or visit **Settings → Recommended tools** to add the tools you want.
