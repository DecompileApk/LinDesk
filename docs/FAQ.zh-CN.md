# 常见问题

[← 返回首页](../README.zh-CN.md) · [首次运行前设置](SETUP.zh-CN.md)

## 需要什么设备？

支持 **Android 11.0 及以上的 ARM64 设备**，无需 Root。首次使用按[首页的快速开始](../README.zh-CN.md#快速开始)操作即可。

## 桌面模式和纯终端模式怎么选？

想用图形应用，选择桌面模式；偏爱纯终端操作，可以直接启动终端，无需加载桌面。两种模式共用文件和软件。

## 如何打开键盘、输入中文？

在桌面点击 **Tools → Keyboard** 打开键盘。想使用手机输入法，在 Linux **Settings** 中选择 **Android host IME**；纯终端模式直接使用手机输入法。**Combos** 提供更多组合键。

## 如何共享文字、传文件和备份？

文字复制后，可切换到 Android 或 Linux 粘贴。文件通过 **Tools → File transfer** 导入或导出。

## 如何安装应用和工具？

- **常用工具：** 在 **设置 → 推荐工具** 中选择并安装。
- **Linux 应用：** 将 **ARM64 Linux `.deb` 安装包**从手机导入，或直接用 Linux 内的浏览器下载。在文件管理器中点开后，按提示安装即可，无需输入命令。

## 如何使用 Codex？

1. 在“设置 → 推荐工具”中安装“AI 编程助手 Codex”。
2. 打开终端，在希望处理的文件夹中运行 `codex`，按提示使用自己的账号登录。

## 如何使用扬声器和麦克风？

播放声音时，用手机媒体音量调节。需要录音时，开启“设置 → 设备访问 → 麦克风”，并允许 Android 录音权限。

## 如何返回首页或停止运行？

**Tools → Back to LinDesk** 返回首页，Linux 继续运行。需要结束时，先保存工作，再点击首页的“停止 Linux”。

<a id="troubleshooting"></a>
## 安装失败或运行中断怎么办？

- **运行中断：** 检查[运行前设置](SETUP.zh-CN.md)，以及手机对 LinDesk 的省电限制。
- **安装失败：** 确认空间充足、下载正常后，重试未完成的项目。已装好的工具会保留。

仍有问题或有建议，欢迎到 [Issues](https://github.com/DecompileApk/LinDesk/issues) 反馈。遇到故障时，请附上 Android 和 LinDesk 版本、操作步骤及错误截图。
