# Frequently asked questions

[← Home](../README.md) · [Before you start](SETUP.md)

## What device do I need?

An **ARM64 device running Android 11.0 or later**. No root required. Follow the [quick start](../README.md#quick-start) to get going.

## Should I choose desktop or terminal mode?

Choose desktop mode for graphical apps. If you prefer working entirely in a terminal, start terminal mode without loading the desktop. Both modes share your files and software.

## How do I open the keyboard or type in another language?

On the desktop, tap **Tools → Keyboard**. To use your phone's keyboard, select **Android host IME** in Linux **Settings**. Terminal mode uses it directly. **Combos** provides more key combinations.

## How do I share text, transfer files or back them up?

Copy text, then switch to Android or Linux to paste it. Use **Tools → File transfer** to import or export files.

## How do I install apps and tools?

- **Common tools:** choose and install them from **Settings → Recommended tools**.
- **Linux apps:** import an **ARM64 Linux `.deb` package** from your phone, or download one using a browser inside Linux. Open it in the file manager and follow the installation prompts. No commands to type.

## How do I use Codex?

1. Install **AI coding with Codex** from **Settings → Recommended tools**.
2. Open a terminal in the folder you want to work with, run `codex` and follow the sign-in prompts using your own account.

## How do I use the speakers and microphone?

Use your phone's media volume for playback. For recording, turn on **Settings → Device access → Microphone** and allow Android's recording permission.

## How do I return to Home or stop Linux?

**Tools → Back to LinDesk** returns to Home while Linux keeps running. To end your session, save your work and tap **Stop Linux** on Home.

<a id="troubleshooting"></a>
## What if installation fails or Linux closes unexpectedly?

- **Unexpected shutdown:** check [Before you start](SETUP.md) and your phone's battery restrictions for LinDesk.
- **Installation failure:** check free space and download access, then retry the unfinished items. Installed tools stay available.

Still having trouble, or have a suggestion? [Open an issue](https://github.com/DecompileApk/LinDesk/issues). For a bug, include your Android and LinDesk versions, what you did and a screenshot of the error.
